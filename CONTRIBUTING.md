# Contributing

This repo is used for the AICodeQuest training study. Every change is a
pull request, and every numbered task PR is played as a short game before
it can be created. Here's the workflow.

## Workflow

1. **Branch.** `git checkout -b m4-refunds` (name it after the task).
2. **Build with your AI assistant.** Open the task's three files (see your
   project README's task table) and implement it. Follow your project's
   coding rules — they exist so the game can grade your code.
3. **Run the app and its tests.** Start the API and web dev servers from
   your project README, click through your feature, and run the test
   suite. Fix anything that breaks before moving on.
4. **Push to your fork.**
5. **Open *Compare & pull request*.** Fill in the PR template below.
6. **Play the game.** For a feature-sized task PR, the extension pauses
   the *Create pull request* button and runs the game (tag your code,
   defend, understand, attack). Pass it to unlock the button.
7. **Create the pull request.**
8. **A teammate reviews and merges.**

## Pull request template fields

- **Task ID** — e.g. `M4`, `B7`, `R2`, `L11`, or `warm-up` / `stretch`.
- **AI assistant(s) used** — name the tool(s) that helped write this.
- **What you built** — one or two sentences.
- **How you tested it** — commands you ran, what you clicked through.
- **Screenshots** — optional, but welcome for UI changes.

See [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md)
for the actual template that pre-fills your PR description.
